RNG independence is GOOD, not a blocker. In train.ts, `const rng=mulberry32(seed)` feeds only `shuffleDeck(rng)` once per hand. Code evidence covers separation; this audit did not record every hidden deck card from engine state. Shared mathematical RNG function does not mean shared mutable stream.
